## SceneKyaHai
- Conversation flow is a focused client state machine in src/routes/index.tsx with draft answers retained across steps; AI handles short reactions, explicit refinement patches and venue picks to keep navigation deterministic.
- Places/geocoding go through the Google Maps gateway in src/lib/places.server.ts; locations rounded to ~1 km — privacy requirement.
- A curation row is inserted only after a successful Plan A/B/C result; free status = zero rows for the device_id — never charge/count failures.
- Shared validated brief and pure eligibility rules live in src/lib/scene.ts, with tests beside them, so distance and country constraints are enforced beyond presentation.
- Opening periods evaluate selected slots in India time; unavailable hours or route durations remain unknown rather than being generated by the model.
- Keep the existing device storage key through rebrands so curation history is not reset; all current charge decisions use the shared curation policy module so suspension applies to returning devices too.
- The conversation state machine begins with a cover state; generated cover and doodle assets provide shared art framing without obstructing interactive content.
- Treat missing Maps address-component types as unknown, not a fatal error; isolate independent venue searches so one failed search cannot discard successful ones.
- Short conversational reactions run without blocking question navigation; discard stale responses so newer answers remain authoritative.
- QuestionArt frames question/refinement screens outside the input area; crop shared surreal artwork by step to keep framing varied without layout shifts.
- StormFinale is a dismissible full-screen canvas ending triggered only by final confirmation; initialize Web Audio in that click, stop it on dismissal, and honor reduced motion.
- Render StormFinale into document.body so page stacking contexts cannot conceal the ending; confirmation feedback must not silently redirect away from lock-in.
